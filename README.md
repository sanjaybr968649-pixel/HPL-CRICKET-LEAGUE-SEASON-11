# HPL — Hand Cricket Premier League

Static GitHub Pages-ready website for HPL Season 11.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub
1. Create a new GitHub repository.
2. Upload all files/folders from this ZIP to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the main branch and `/ (root)`.
6. Save. GitHub will publish the site.

## Included
- Animated HPL welcome/splash screen
- Home dashboard
- Season 11
- Teams + logos + home grounds
- Players + profile pages
- HPL career stats
- Match cards + scorecards
- Stats and all-time records sections
- Responsive mobile/desktop layout
- Supplied HPL/team logos
- Supplied local player photos for Sanjay and Darshan

## Important
This is a front-end/static build. A real admin panel, database, live score updates, authentication, and automatic persistent statistics require a backend/database to be connected later.

No date/time fields are used in the match UI, as requested.
