# HPL — Hand Cricket Premier League

Static GitHub Pages website. All asset paths are relative (`./assets/...`) so it works when published under a GitHub repository path.

## GitHub Pages
1. Upload every file/folder in this project to the repository root.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch** → `main` → `/ (root)` → Save.
4. Open the generated Pages URL.

Do not rename or move `assets`, `styles.css`, `app.js`, `data.js`, or `index.html` unless you also update the relative paths.
