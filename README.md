# HPL Client Ready Website

Static GitHub Pages website for Hand Cricket Premier League Season 11.

## Upload
Upload the **contents of this folder** to the repository root. `index.html` must be in the root.

## Included
- Working HPL logo and all four team logos from the supplied assets
- Welcome animation using the supplied HPL/Virat/Dhoni promotional artwork
- Season 11 matches and scorecards from the supplied handwritten records
- Local player profiles and Season 11 run totals
- Pre-Season cumulative local-player records supplied in the handwritten table, combined with Season 11 totals
- Teams, grounds, player search, stats and records
- No external image/CDN dependency
- Mobile responsive layout
